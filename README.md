# Meteor Strike Download Page

Standalone static landing page for the Google Play release of **Meteor Strike** by **Striking Games**.

The hero phone panel now includes a playable JavaScript mini-game that mirrors the Unity gameplay loop more closely than the earlier decorative demo.

## Files

- `index.html`
- `styles.css`
- `demo.js`
- `assets/`

## Preview

Open `index.html` directly in a browser, or serve this folder with any simple static file server.
